Fallback Recovery And Batch Parsing
src/parse.js:1-11
importantNot viewed
parse now catches exceptions from JSON.parse and returns the supplied fallback, defaulting to null; malformed JSON therefore no longer propagates an error. This also means callers using the default cannot distinguish a parse failure from successfully parsing the JSON value null. The new parseAll maps inputs in order and delegates each item to parse, so individual parse failures become fallback entries rather than aborting the batch. If the fallback is an object, every failed item receives the same object reference. Failures outside the delegated parse—such as items not supporting map—still propagate. These effects are confirmed by the code; whether silent recovery, null, and shared fallback identity are the desired public semantics is unknown.
