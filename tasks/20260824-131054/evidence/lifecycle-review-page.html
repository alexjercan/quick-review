Enforce Expiry And Touch Session
src/session.js:1-14
importantNot viewed
open reads the session, preserves the existing missing-entry result, and now treats expiresAt <= now as expired: it deletes the stored entry and returns undefined. Thus expiry is enforced lazily during lookup, including at the exact boundary. touch sets expiresAt to now + ttl on the supplied object and returns that same object; it does not interact with the store, so durable renewal depends on object-reference semantics or a caller write-back. The code performs no type or range checks: a missing or nonnumeric expiresAt may evade expiry through JavaScript coercion, while a string, negative, or otherwise invalid ttl can produce an unintended value. Whether upstream code guarantees numeric timestamps and TTLs is unknown because no contract or callers exist in the repository.
